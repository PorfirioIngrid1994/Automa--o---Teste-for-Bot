IDs Únicos em todos os inputs para driver.find_element(By.ID, '...')

Guia de IDs dos Elementos (Cheat Sheet)

Abaixo estão os IDs para copiar e usar direto no seu script Python (Selenium / Playwright):

Exemplo em Python (Selenium):
from selenium import webdriver
from selenium.webdriver.common.by import By

driver = webdriver.Chrome()
driver.get("http://localhost:5500") # Ou caminho local do index.html

# Login
driver.find_element(By.ID, "login-usuario").send_keys("admin")
driver.find_element(By.ID, "login-senha").send_keys("123456")
driver.find_element(By.ID, "btn-login-submit").click()

# Preencher Cadastro
driver.find_element(By.ID, "nome_completo").send_keys("Carlos Silva")
driver.find_element(By.ID, "cpf").send_keys("123.456.789-00")
driver.find_element(By.ID, "email").send_keys("carlos@teste.com")
driver.find_element(By.ID, "btn-cadastrar").click()
